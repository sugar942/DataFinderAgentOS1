# DataFinderAgentOS 角色定义与职责

## 1. 系统简介

DataFinderAgentOS 是一套面向政务领域的智能瞭望与问数系统，采用 Tornado 框架构建 Web B/S 架构，遵循 MVC 分层设计。系统包含用户端（前台）和管理端（后台），集成大模型对话能力，通过 WebSocket 与 OpenAI API 实现实时智能交互。

**用户端（前台）**: 提供对话式数据查询体验，用户可通过自然语言与数据交互，获得统计分析、图表报告，类似 ChatGPT 的智能应用形态。

**管理端（后台）**: 提供系统全局管理，包含用户权限、数据瞭望、采集调度、AI 引擎配置、可视化大屏等功能。

**核心技术补充：**
- **前端**: layui（主力）+ Bootstrap（辅助），已本地化至 `app/static/dist/`
- **实时通信**: WebSocket（Tornado 内置）
- **AI 引擎**: OpenAI API

## 2. 角色划分

| 角色 | 权限范围 | 对应模块 |
|------|----------|----------|
| 普通用户 | 登录、注册、智能问数对话、智能助手调用、报表分析、历史查看、报告导出 | 用户端全部功能 |

| 对话历史 | 自动生成标题、历史对话列表、切换/删除对话 |
| 快捷功能 | /前缀激活快捷操作菜单（预留） |

### 2.4 AI 开发助手

作为 AI 开发助手，在本项目中的定位：

**主要职责：**
- 理解项目架构和技术栈，遵循既有代码风格
- 按需求文档实现功能或修复缺陷
- 维护提示工程文档（role.md、constraint.md、requirement.md、template.md、test_case.md）
- 编写单元测试保证代码质量
- 执行代码审查和安全检查

**工作准则：**
- 遵守 MVC 分层架构
- 使用 SQLite3 进行数据操作，避免引入额外依赖
- 密码安全使用 pbkdf2_hmac + salt
- 遵循 XSRF 防护规范
- 使用安全 Cookie 管理会话
- 代码风格与既有代码保持一致
- 前端优先 layui，Bootstrap 按需补充
- 大模型通信使用 WebSocket + OpenAI API

## 3. 开发工作流

AI 开发助手按以下流程推进：
1. 阅读需求文档（requirement.md）
2. 查阅约束文档（constraint.md）
3. 参考模板规范（template.md）
4. 编码实现功能
5. 编写测试用例（参考 test_case.md）
6. 同步更新相关文档
